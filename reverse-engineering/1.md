**2) Consider the following bytecode:**

**LDC 0**

**LDC 3**

**SWAP**

**POP**

**INEG**

**Which value is now at the top of the stack?**

```
Think like this:
LDC 0 
loads 0 into the empty stack [] like [0]

LDC 3 
loads 3 into the stack [3, 0]

SWAP
swaps the values latest 2 values in stack becomes [0, 3]

POP
removes the value at top currently its 0 so its removed now remains [3] in stack

INEG
makes a intiger negative so the 3 in stacks beconems [-3]
```
