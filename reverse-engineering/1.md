**Which value is now at the top of the stack?**

```
LDC 0
Stack: [] → [0]
        └── loads 0 into the empty stack

LDC 3
Stack: [0] → [3, 0]
        └── loads 3 onto the stack

SWAP
Stack: [3, 0] → [0, 3]
        └── swaps the top 2 values

POP
Stack: [0, 3] → [3]
        └── removes the top value (0)

INEG
Stack: [3] → [-3]
        └── negates the integer at the top of the stack
```

> -3

**3) What is the value of the local variable in slot 1 when the method returns? (In decimal format)**

```
Look at public static void main(java.lang.String[]);
 Code:
      stack=2, locals=2, args_size=1
         0: iconst_0
         1: istore_1
         2: getstatic     #2                  // Field java/lang/System.out:Ljava/io/PrintStream;
         5: ldc           #3                  // String Hello World
         7: invokevirtual #4                  // Method java/io/PrintStream.println:(Ljava/lang/String;)V
        10: iinc          1, 2
        13: return

First, iconst_0 pushes the value 0 onto the operand stack, and istore_1 stores that value in local variable slot 1.
At the end, iinc 1, 2 increments the value in local variable slot 1 by 2, so the value changes from 0 to 2.
```

### Task 4 : Basic string obfuscation

**What is the correct password?**

```
what the program compares your input against

In main():

10: ldc #3                  // String aRa2lPT6A6gIqm4RE
12: invokestatic #4         // Method xor:(Ljava/lang/String;)Ljava/lang/String;
15: aload_1
18: invokevirtual #5        // String.equals(...)

program does:
xor("aRa2lPT6A6gIqm4RE").equals(yourInput)  // reverse xor function..

xor():
18: aload_1
19: iload_3
20: caload
...
27: iload_3
28: iconst_3
29: irem
30: ixor

this corresponds roughly to:

for (int i = 0; i < chars.length; i++) {
    char c = chars[i];
    result[i] = (char)(c ^ (i % 3));
}

Let us use python to decode it:

skid@TheGreen:~/ctfs$ python3 -c 's="aRa2lPT6A6gIqm4RE";print("".join(chr(ord(c)^(i%3)) for i,c in enumerate(s)))'
aSc2mRT7C6fKql6RD

Testing it:

skid@TheGreen:~/ctfs$ java BasicStringObfuscation aSc2mRT7C6fKql6RD
Correct!
skid@TheGreen:~/ctfs$
```

> aSc2mRT7C6fKql6RD
